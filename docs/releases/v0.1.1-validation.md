# v0.1.1 发布准备验收

日期：2026-11-12。范围：本次安全修复和默认关闭的 MCP 基础接入。此记录是发布准备，不表示已经推送标签、公开 Release 或更新镜像。

## 真实迁移库升级

使用隔离测试服务器现有 YApi MongoDB 数据，先由 v0.1.0 的迁移程序生成 schema 1 SQLite 库，再用 v0.1.1 启动同一副本。源 YApi 服务与 MongoDB 数据未作重置或更新。

| 检查 | 结果 |
|---|---|
| 项目 / 接口 | 4 个项目、59 个接口 |
| schema 升级 | 1 → 2 |
| 读取响应对比 | 79 个响应一致，含项目、成员、分类、接口详情 |
| 账号与原密码 | 登录成功 |
| 旧 token | 4 个均可读取接口，项目管理请求均拒绝 |
| 新 token | 独立签发，4 个在重启后仍有效 |
| 数据库 | 原有表行数一致，integrity_check 与 foreign_key_check 通过 |
| 升级前备份 | 创建成功，完整性与原库行数一致 |
| MCP 默认状态 | HTTP 404 |

复现脚本：[validate-upgrade.py](../../testenv/release/validate-upgrade.py)。脚本只应接收离线测试副本和独立输出目录；登录密码由环境变量提供，token 仅在内存中比较，不写入验收日志。

## 浏览器核心流程

通过连接测试服务器回环地址的 SSH 隧道，使用真实浏览器完成：

- 错误密码提示、原账号登录及退出指引。
- 打开迁移分组、项目和接口列表。
- 新建验收接口，编辑名称和 Query 参数，保存成功。
- 刷新后名称、参数示例和备注仍在。
- 项目动态出现新增与修改记录。
- 退出后跳到携带原页面地址的登录页，重新登录返回原动态页。
- Mock 路由正常返回 JSON。

验收数据仅写入升级后的 SQLite 副本。桌面窗口捕获通道不可用时使用了浏览器专用通道。控制台仍记录旧前端的 Network Error；当前前端存在 CSP 禁止外部版本检查的既有行为，因此此记录不声称控制台完全无错误，核心流程以页面结果和持久化数据为依据。
