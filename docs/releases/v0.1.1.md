# v0.1.1 发布说明（待发布）

这是 v0.1 的安全与可靠性修复版本，建议现有部署升级。发布前请先备份数据库。

## 安全修复

- 修复角色查询泄露私有项目环境配置、成员信息的问题。
- 修复分组动态绕过私有项目权限，泄露接口历史定义的问题。
- 改用服务端随机签发、绑定用户的项目凭据；新凭据遵守签发用户的当前权限，项目 token 重置会撤销全部已签发凭据。
- 旧 YApi token 中的 uid 不再授予用户或管理员角色，防止利用默认加密口令伪造项目管理身份。
- 为 Schema 和 Mock.js 生成增加节点、长度、字节、递归、并发预算以及请求取消检查，限制嵌套模板、占位符和正则放大。
- 升级 compress 至 v1.20.2、x/text 至 v0.39.0，修复依赖调用链中的已知问题。

## 可靠性与发布

- 迁移增加目标排他锁、唯一临时库和替换前持久备份；不再先删除旧库，拒绝替换存在活跃 WAL 等侧文件的目标。
- 二进制与镜像发布统一受测试、vet 和漏洞检查门禁约束；附件增加 Go 模块清单和校验值。
- MCP 仍在开发，v0.1.1 默认关闭；完整工具和真实客户端验收属于 v0.2。

## 兼容性变化

原有 YApi token 保留所属项目的接口查询和编辑能力，统一作为 system 集成身份使用，不能管理项目。需要项目管理能力或 MCP 的客户端，应从项目设置重新获取 ApiYard 新 token。新版 token 仍为 64 位十六进制，使用的 HTTP 路径和 token 参数不变。

旧 token 属于项目级能力，不能根据某个用户降权自动吊销；如需收回旧凭据，重置项目 token。新 token 则遵守签发用户当前权限。超出生成预算的 Mock 模板会返回受控错误，超过并发配额返回 429。

## 升级与恢复

1. 停止 ApiYard，备份数据库；正常退出会完成 WAL checkpoint。
2. 更换可执行文件或镜像，使用原数据库与配置启动。数据库自动从 schema 1 升至 2，原账号密码、项目、接口 ID 和链接保留。
3. 验证登录、接口读取及集成工具。需要管理权限的旧集成换用新 token。
4. 若需回退，停止服务，保留升级后的数据库用于恢复增量，再恢复升级前备份并运行旧版本；不要把回退等同于仅更换二进制。
