ApiYard

团队的接口文档、Mock 和协作，放在一处

兼容 YApi 的轻量接口管理平台。熟悉的操作方式，更简单的部署。

  • 一个可执行文件加一个 SQLite 文件，不需要 Node.js 和 MongoDB
  • 一条命令从 YApi 迁移，账号、token 和 Mock 地址照常可用
  • 内网部署时不向外部发送任何数据
GET/mock/11/pay/orders/{id}
{
  "order_id": "PO20261109001",
  "amount": 128.5,
  "status": "paid"
}
